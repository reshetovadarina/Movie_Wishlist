# Movie Wishlist 🎬

Сучасний модульний веб-додаток для створення персонального списку бажаних фільмів із можливістю інтеграції та пошуку у світовій базі кінематографа OMDb API.

## 📱 Демонстрація

https://github.com/reshetovadarina/movies_my_project/blob/main/Movie_Wishlist.png

## ⚡ Можливості додатку

*   **Керування списком:** додавання фільмів вручну із зазначенням назви, року випуску, жанру та статусу перегляду.
*   **Інтеграція з OMDb API:** асинхронний пошук фільмів за назвою та відображення отриманих даних (постер, назва, рік).
*   **Збереження з API:** можливість додавати знайдені фільми до локального списку.
*   **Збереження стану:** автоматичний запис списку фільмів та обраної теми у `localStorage`.
*   **Безпека даних:** дані виводяться через `textContent`, щоб уникнути XSS-атак.
*   **Адаптивна верстка:** інтерфейс оптимізовано під мобільні екрани за допомогою CSS Flexbox та медіазапитів (`@media`).
*   **Доступність (A11y):** використання семантичних тегів `<label>` для полів форми ручного додавання та налаштування видимості фокусу клавіатури.
*   **Зміна теми:** перемикання між світлим та темним режимами інтерфейсу.
## 🛠️ Стек технологій

- **HTML5** (Семантична доступна верстка)
- **CSS3** (Custom Scrollbars, Transitions, Media Queries)
- **Vanilla JavaScript** (Чистий JS без сторонніх бібліотек)
- **ES6+ Modules** (Модульна архітектура проекту)
- **OMDb API** (Світова база даних фільмів)

## 📂 Структура проекту

У корені проекту залишаються виключно головна сторінка інтерфейсу та документація. Усі допоміжні файли структуровані за відповідними каталогами:

*   `index.html` — Семантичний каркас сторінки та форми без інлайн-стилів (знаходиться в корені).
*   `README.md` — Головна інструкція, опис екосистеми та документація проекту (знаходиться в корені).
*   `css/` — Спеціалізована папка для стилів:
    *   `css/style.css` — Глобальний файл оформлення, адаптивні медіазапити, анімації та класи темної теми.
*   `js/` — Ізольована папка для логіки та ES-модулів додатка:
    *   `js/script.js` — Головна точка входу, яка ініціалізує додаток та запускає старт програми.
    *   `js/events.js` — Обробники подій клавіатури, миші та перемикання вкладок, які зв'язують модулі докупи.
    *   `js/state.js` — Ізольоване керування масивом даних, збереження стану та чиста робота з `localStorage`.
    *   `js/render.js` — Відмальовування елементів інтерфейсу, карток фільмів, тостів та повідомлень завантаження в DOM.
    *   `js/api.js` — Модуль для виконання асинхронних мережевих запитів (`fetch`, `async/await`) до OMDb.
    *   `js/movies.js` — Початковий дефолтний масив фільмів для першого старту додатку.
    *   `js/helpers.js` — Допоміжні загальні утиліти (генерація унікальних ID, функція `debounce`).
    *   `js/validation.js` — Чисті логічні перевірки форми на дублікати фільмів та роки випуску.

## 🔑 Примітка про API-ключ

У цьому проекті для виконання запитів використовується безкоштовний API-ключ.
Він навмисно залишений відкритим у файлі `api.js` та збережений у публічному репозиторії, оскільки:

1. Це навчальний некомерційний проект з обмеженими лімітами запитів на добу.
2. Ключ не містить приватних платіжних або персональних даних розробника.
3. Проект розгортається на GitHub Pages як статичний сайт (без бекенду), де будь-які ключі все одно будуть видимі у вкладці Network браузера користувача.
